# 📊 Super Store Sales Performance Dashboard

An interactive Excel Dashboard built using Pivot Tables, Pivot Charts, Slicers, and Dashboard Design techniques to analyze Super Store sales performance.

---

## 📌 Project Overview

This dashboard helps business users analyze sales, profit, customer behavior, shipping performance, and product performance through an interactive interface.

The dashboard allows filtering by:

- Customer Segment
- Payment Mode
- Region
- Product Category
- Product Sub Category
- Year
- Quarter

## Dashboard Insights

- California generated the highest sales.
- Office Supplies contributed the largest sales volume.
- Technology category generated the highest profit.
- Most customers are repeat buyers.
- Orders with 5+ purchases dominate customer ordering behavior.
- Shipping takes approximately 4 days on average.
